🛡️ OktamaDnsFilter

Sistem pertahanan privasi dan pemblokir iklan tingkat sistem tanpa memerlukan akses root di perangkat Android atau Windows.

  • 💻 Multi-Arsitektur: Windows (x64), Android (ARM64, ARMv7, x86)
  • ⚡ Enkripsi DNS Canggih: Dukungan penuh DNS over HTTPS (DoH) & DoT
  • 🚫 Perlindungan Menyeluruh: Blokir iklan, pelacak data, judi online, dan malware
  • 🔒 Tanpa Root: Berjalan aman via VPN Service lokal
